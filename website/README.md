# Geeked IDE website

The landing page for [Geeked IDE](https://github.com/elliott964/geeked-ide), live at https://geeked.yeahelliott.com.

Built with Next.js (App Router) and deployed on Vercel. Screenshots in `assets/` are captured from the real app.

```bash
npm install
npm run dev
```

The download link and version live in `components/site.ts`. Update them when you publish a new release.
